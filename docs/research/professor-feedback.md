# Professor Feedback — Current Source of Truth

## Meeting: August 2026

### Core direction

The project should focus on:

Academic exploratory search
+
Metacognitive scaffolding
+
Search triage
+
Cross-session search resumption

### Explicit scope boundary

Do not move into information extraction as part of the studied
search workflow.

Users should search, find, evaluate search-result relevance,
save resources, organize them, and later return to continue searching.

Reading and extracting information from the actual documents is
a later activity and is outside the primary study.

### Search triage

The system should help users reduce a large set of academic search
results into a smaller set of potentially useful saved resources.

The search-result metadata should provide enough information for
users to decide whether a result is worth saving.

### Organization

When a user saves a result, the system may suggest where it belongs
within the user's metacognitive search plan.

The user should retain control over this decision.

### Planning

Metacognitive planning means more than having one "research plan."

The system should help users define:

- search goal
- what they already know
- what they want to find
- search directions

The system can help structure and revise these.

### Cross-session resumption

The system should help users reconstruct their previous search state
after an interruption.

The resume experience should guide the user through:

- where they were
- what they did
- what they found
- what they saved
- what direction they were pursuing
- how they can continue

### Navigation

Avoid large collections of independent tabs.

Prefer guided navigation / breadcrumb-like progression.

The scaffold should guide users toward what they need next.

### User agency

AI should support the user rather than replace their decisions.

However, minimizing interaction friction is especially important
for users with dyslexia.

Therefore, AI suggestions should require minimal interaction while
still allowing users to override them.

### Explicitly rejected direction

Do not build the thesis around:

Claims → Observations → Insights → Research Gaps.

Research-gap generation is outside the project scope.
