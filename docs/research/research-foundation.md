## Core Theoretical Concepts

### Metacognition

Metacognition concerns awareness and regulation of one's own
cognitive processes.

For this project:

Cognition = searching.

Metacognition = planning, monitoring, evaluating and revising
the search process.

### Distributed Cognition

External representations can participate in cognitive processes.

This motivates externalizing search state.

### Cognitive Offloading

Users can reduce internal memory demands by relying on external
representations.

The system applies this specifically to search state.

### Exploratory Search

Exploratory search involves open-ended information seeking where
the user's understanding and search direction may evolve.

### Cross-Session Search

A search task can span multiple sessions separated by time.

The system should support continuity between these sessions.

### Search Triage

Searchers often need to reduce a large result set into a smaller
set of potentially useful resources before conducting deeper
information extraction.
