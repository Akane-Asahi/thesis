Before designing:

Read:
- CLAUDE.md
- docs/research/professor-feedback.md
- docs/design/ui-specification.md
- relevant user-flow documentation.

Design only within the current research scope.

For every screen specify:
- purpose
- user state
- visible information
- components
- AI-generated content
- user-generated content
- interaction
- transition to next state

Do not add features merely because they look useful.

Every component must support:
- planning
- monitoring
- evaluation
- revision
- search triage
- organization
- or cross-session resumption.

Finally create a .md file inside design folder with the name of the screen page name
